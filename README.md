# Dock Reloaded

[<img src="https://raw.githubusercontent.com/andyholmes/gnome-shell-extensions-badge/master/get-it-on-ego.svg?sanitize=true" height="100" align="right">](https://extensions.gnome.org/extension/5269/dock-reloaded/)

[GNOME Shell](https://www.gnome.org/) extension that adjust Dock behavior:

-   moves it top
-   autohide ---> !reveals under cursor pressure! <---
-   shows only favorites apps

## Installation

Grab it from [extensions.gnome.org](https://extensions.gnome.org/extension/5269/dock-reloaded/) or unzip to: ~/.local/share/gnome-shell/extensions.
